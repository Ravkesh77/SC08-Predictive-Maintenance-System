# SC08 Predictive Maintenance System - Data Documentation

## Project Purpose
Predict industrial equipment failures before they occur based on real-time sensory measurements (temperatures, rotational speed, torque, and tool wear).

## Primary Labelled Dataset
- **Dataset:** AI4I 2020 Predictive Maintenance Dataset
- **Source:** [UCI Machine Learning Repository (Dataset ID: 601)](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Downloaded File:** `data/raw/ai4i2020.csv`
- **Source Records:** 10,000
- **Target:** `Machine failure` (0 = No failure, 1 = Equipment failure)

## Input Fields
- `Air temperature [K]`: Ambient temperature in Kelvin generated by random walk (295.3 K to 304.4 K)
- `Process temperature [K]`: Machine process temperature in Kelvin (305.7 K to 313.8 K)
- `Rotational speed [rpm]`: Spindle speed in rotations per minute (1168 to 2886 rpm)
- `Torque [Nm]`: Resistance torque in Newton meters (3.8 to 76.6 Nm)
- `Tool wear [min]`: Cumulative tool usage time in minutes (0 to 253 min)
- `Type`: Quality grade variant of the product (L = low, M = medium, H = high)
